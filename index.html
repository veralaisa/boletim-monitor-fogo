              Acesse os dados

                De onde vêm os números

                Todos os dados vêm do Monitor do Fogo, do MapBiomas Fogo: o mapeamento mensal das cicatrizes de fogo (área queimada) no Brasil, feito com imagens de satélite Sentinel-2, a partir de 2019. Os números são lidos da API pública da plataforma no momento em que o boletim é aberto; nenhum dado é mapeado ou corrigido aqui.
